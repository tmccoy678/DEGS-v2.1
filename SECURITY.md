# Security policy

## Scope and support

This is a private development draft, with no versioned public release or security certification. Taylor welcomes reports against the current draft main branch and will investigate on a best-effort basis. No response deadline or backport support is promised. Record the exact affected commit; a passing test or scan does not prove that a version is secure.

## Report a concern

Do not put secrets, credentials, personal records, or exploit details in issues or pull requests. Contact [Taylor (@tmccoy678)](https://github.com/tmccoy678) using an already established private channel. If you do not have one, open an issue asking only for a private security contact, without vulnerability details. A GitHub profile is not itself a private messaging channel. This draft does not claim that GitHub private vulnerability reporting is configured.

Once a private channel is established, include the affected commit, expected and observed behavior, a minimal sanitized reproduction, impact, environment, and any mitigation. Synthetic fixtures are preferable to private task records. Taylor will respond as quickly as possible and appreciates help improving the work.

## Boundaries to understand

The demonstrations are bounded examples. They do not install background services, grant task authority, or authorize device or credential access. DEGS evaluates recorded evidence; it does not prove that the evidence is true or prevent arbitrary commands outside its interface. Sashiko-derived review data remains untrusted evidence, not permission or a final decision.

The draft may retain historical private-project documentation and provenance from its source repository. Private access is not public-release clearance. Review history, assets, licenses, fixtures, and generated outputs before any public distribution. Only the recorded Apple-silicon environment has been tested in this workflow.

For ordinary questions or improvements, use the repository's issues without sensitive details. See the README for runnable examples, test scope, and current limitations.
