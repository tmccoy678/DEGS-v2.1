# Evidence Gate

Evidence Gate is a deterministic, read-only readiness evaluator for structured engineering task records. It checks whether a record contains the intent, risk, authority, evidence, recovery, verification, validation, review, and handoff controls required by the selected local risk tier. It returns a decision and diagnostics; it does not execute the task, establish that evidence is true, or grant approval.

Its control model is a tailored local synthesis of the source register behind the DobeWorks Engineering Governance System: systems and software engineering standards and handbooks, secure-development and software-supply-chain guidance, foundational engineering literature, and bounded public industry practices. Those sources inform local controls without transferring their applicability, endorsement, certification, or compliance.
